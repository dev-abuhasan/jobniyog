# স্টেপ ০৭ - অসমতা

অসমতা হলো দুটি রাশি বা পদের মধ্যে পারস্পরিক মানের তুলনা, যেখানে সমান (=) চিহ্নের পরিবর্তে `>`, `<`, `≥`, অথবা `≤` চিহ্ন ব্যবহৃত হয়। বিসিএস প্রিলিমিনারি পরীক্ষায় মূলত রৈখিক অসমতা (Linear Inequality), মডুলাস বা পরম মান (Modulus) সংক্রান্ত অসমতা এবং দ্বিঘাত অসমতা থেকে প্রশ্ন আসে।

---

## ১. অসমতার মৌলিক নিয়মাবলি (Basic Rules)

১. **উভয়পক্ষে যোগ বা বিয়োগ:** অসমতার উভয়পক্ষে একই সংখ্যা যোগ বা বিয়োগ করলে অসমতার চিহ্নের কোনো পরিবর্তন হয় না।
   - যদি $a > b$ হয়, তবে $a + c > b + c$ এবং $a - c > b - c$

২. **ধনাত্মক সংখ্যা দ্বারা গুণ বা ভাগ:** কোনো ধনাত্মক সংখ্যা দ্বারা উভয়পক্ষকে গুণ বা ভাগ করলে অসমতার দিক অপরিবর্তিত থাকে।
   - যদি $a > b$ এবং $c > 0$ হয়, তবে $ac > bc$

৩. **ঋণাত্মক সংখ্যা দ্বারা গুণ বা ভাগ (সবচেয়ে গুরুত্বপূর্ণ নিয়ম):** কোনো ঋণাত্মক সংখ্যা দ্বারা উভয়পক্ষকে গুণ বা ভাগ করলে অসমতার দিক বা চিহ্ন উল্টে যায় (`>` থাকলে `<`, এবং `<` থাকলে `>`)।
   - যদি $a > b$ এবং $c < 0$ হয়, তবে $ac < bc$

৪. **ব্যস্তকরণ (Reciprocal):** উভয়পক্ষের চিহ্ন একই হলে ব্যস্ত করলে অসমতার দিক পরিবর্তিত হয়।
   - যদি $a > b > 0$ হয়, তবে $\frac{1}{a} < \frac{1}{b}$

## ২. গুরুত্বপূর্ণ সূত্র ও শর্টকাট

- **ধর্ম ১:** যদি $\vert{}x\vert{} < a$ হয় (যেখানে $a > 0$), তবে $-a < x < a$ হবে।
- **ধর্ম ২:** যদি $\vert{}x\vert{} > a$ হয় (যেখানে $a > 0$), তবে $x > a$ অথবা $x < -a$ হবে।
- **ধর্ম ৩ (দ্বিঘাত অসমতা):** যদি $(x - a)(x - b) < 0$ হয় (যেখানে $a < b$), তবে মূলদ্বয়ের মধ্যবর্তী মান হবে, অর্থাৎ $a < x < b$।
- **ধর্ম ৪ (দ্বিঘাত অসমতা):** যদি $(x - a)(x - b) > 0$ হয় (যেখানে $a < b$), তবে মূলদ্বয়ের বাইরের মান হবে, অর্থাৎ $x < a$ অথবা $x > b$।


বাস্তব সংখ্যা রেখায় (Real Number Line) দুটি নির্দিষ্ট বিন্দুর মধ্যবর্তী বা বাইরের মানসমূহকে প্রকাশ করার জন্য ব্যবধি বা ইন্টারভ্যাল ব্যবহার করা হয়। এখানে ব্যবধির প্রধান ৯টি রূপ ছক আকারে দেওয়া হলো:

| ক্রম | ব্যবধির নাম (Name) | স্বরলিপি / সেট গঠন (Set Builder Form) | ব্যবধি প্রকাশ (Interval Notation) | সংখ্যা রেখায় প্রকাশ (Number Line Representation) |
| :--- | :--- | :--- | :--- | :--- |
| ১. | উন্মুক্ত ব্যবধি (Open Interval) | $\{x \in \mathbb{R} \mid a < x < b\}$ | $(a, b)$ | $a$ থেকে $b$ পর্যন্ত (সীমান্ত বিন্দু বর্জিত) |
| ২. | বদ্ধ ব্যবধি (Closed Interval) | $\{x \in \mathbb{R} \mid a \le x \le b\}$ | $[a, b]$ | $a$ ও $b$ সহ তাদের মধ্যবর্তী সকল মান |
| ৩. | বামে বদ্ধ, ডানে উন্মুক্ত (Left-Closed, Right-Open) | $\{x \in \mathbb{R} \mid a \le x < b\}$ | $[a, b)$ | $a$ সহ কিন্তু $b$ বর্জিত |
| ৪. | বামে উন্মুক্ত, ডানে বদ্ধ (Left-Open, Right-Right) | $\{x \in \mathbb{R} \mid a < x \le b\}$ | $(a, b]$ | $a$ বর্জিত কিন্তু $b$ সহ |
| ৫. | উন্মুক্ত রশ্মি / অসীম উন্মুক্ত (Open Ray / Infinite Open) | $\{x \in \mathbb{R} \mid x > a\}$ | $(a, \infty)$ | $a$-এর চেয়ে বড় সকল সংখ্যা |
| ৬. | বদ্ধ রশ্মি (Closed Ray) | $\{x \in \mathbb{R} \mid x \ge a\}$ | $[a, \infty)$ | $a$ সহ তার চেয়ে বড় সকল সংখ্যা |
| ৭. | বামমুখী উন্মুক্ত রশ্মি (Left Open Infinite Ray) | $\{x \in \mathbb{R} \mid x < b\}$ | $(-\infty, b)$ | $b$-এর চেয়ে ছোট সকল সংখ্যা |
| ৮. | বামমুখী বদ্ধ রশ্মি (Left Closed Infinite Ray) | $\{x \in \mathbb{R} \mid x \le b\}$ | $(-\infty, b]$ | $b$ সহ তার চেয়ে ছোট সকল সংখ্যা |
| ৯. | সমগ্র বাস্তব সংখ্যা সেট (Real Number Line) | $\{x \in \mathbb{R} \mid -\infty < x < \infty\}$ | $(-\infty, \infty)$ | মাইনাস ইনফিনিটি থেকে প্লাস ইনফিনিটি পর্যন্ত সকল বাস্তব সংখ্যা |

### গুরুত্বপূর্ণ নোট:
- **প্রথম বন্ধনী `( )`** ব্যবহার করা হয় যখন সীমানা বা প্রান্তীয় বিন্দুটি **অন্তর্ভুক্ত নয়** (`<` বা `>`)। একে উন্মুক্ত (Open) বোঝায়।
- **তৃতীয় বন্ধনী `[ ]`** ব্যবহার করা হয় যখন সীমানা বা প্রান্তীয় বিন্দুটি **অন্তর্ভুক্ত** (`\le` বা `\ge`)। একে বদ্ধ (Closed) বোঝায়।
- অসীমের (`\infty`) সাথে সবসময় উন্মুক্ত বন্ধনী `( )` বা ফার্স্ট ব্র্যাকেট বসে, কারণ অসীম কোনো নির্দিষ্ট সংখ্যা নয়।

## ৩. বিসিএস স্ট্যান্ডার্ড নমুনা প্রশ্ন ও সমাধান

### প্রশ্ন ১: 
যদি $3x - 5 < 7$ হয়, তবে $x$-এর মান কত?

**সমাধান:**
প্রদত্ত অসমতা: 
$3x - 5 < 7$
উভয়পক্ষে $5$ যোগ করে পাই,
$3x < 7 + 5$
$3x < 12$
উভয়পক্ষকে $3$ দ্বারা ভাগ করে পাই,
$x < 4$

**উত্তর:** $x < 4$

---

### প্রশ্ন ২:
$-2 \le 3x + 1 < 10$ হলে, $x$-এর মানসীমা নির্ণয় কর।

**সমাধান:**
অসমতাটিকে সমাধান করতে হলে মাঝখান থেকে $x$ একা করতে হবে।
$-2 \le 3x + 1 < 10$
সব পক্ষে $1$ বিয়োগ করে পাই,
$-2 - 1 \le 3x < 10 - 1$
$-3 \le 3x < 9$
সব পক্ষকে $3$ দ্বারা ভাগ করে পাই,
$-1 \le x < 3$

**উত্তর:** $-1 \le x < 3$

---

### প্রশ্ন ৩:
$\vert{}2x - 3\vert{} < 5$ অসমতাটির সমাধান সেট কোনটি?

**সমাধান:**
আমরা জানি, $\vert{}x\vert{} < a$ হলে $-a < x < a$ হয়।
অতএব, 
$-5 < 2x - 3 < 5$
সব পক্ষে $3$ যোগ করে পাই,
$-5 + 3 < 2x < 5 + 3$
$-2 < 2x < 8$
সব পক্ষকে $2$ দ্বারা ভাগ করে পাই,
$-1 < x < 4$

**উত্তর:** $-1 < x < 4$

---

### প্রশ্ন ৪:
$x^2 - 5x + 6 < 0$ অসমতার সমাধান কত?

**সমাধান:**
প্রথমে উৎপাদকে বিশ্লেষণ করি:
$x^2 - 3x - 2x + 6 < 0$
$x(x - 3) - 2(x - 3) < 0$
$(x - 2)(x - 3) < 0$

এটি $(x - a)(x - b) < 0$ ফরম্যাটে আছে যেখানে $a = 2, b = 3$।
নিয়ম অনুযায়ী, মূলদ্বয়ের মধ্যবর্তী মান হবে।
অতএব, $2 < x < 3$

**উত্তর:** $2 < x < 3$
