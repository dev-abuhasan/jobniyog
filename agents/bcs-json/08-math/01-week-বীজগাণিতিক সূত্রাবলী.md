### **Type 01: বর্গের সূত্র এবং অনুসিদ্ধান্তসমূহের প্রয়োগ**

**01:** $x^2 + y^2 + z^2 = 2$, $xy + yz + zx = 1$ হলে, $(x + 2y)^2 + (y + 2z)^2 + (z + 2x)^2$ এর মান- [৪৬তম বিসিএস]
(ক) 12   (খ) 19  (গ) 16  (ঘ) 14

**সমাধান:**

দেওয়া আছে, $x^2 + y^2 + z^2 = 2$, $xy + yz + zx = 1$

প্রদত্ত রাশি,  
$$= (x + 2y)^2 + (y + 2z)^2 + (z + 2x)^2$$
$$= x^2 + 4xy + 4y^2 + y^2 + 4yz + 4z^2 + z^2 + 4zx + 4x^2$$
$$= 5x^2 + 5y^2 + 5z^2 + 4xy + 4yz + 4zx$$
$$= 5(x^2 + y^2 + z^2) + 4(xy + yz + zx)$$
$$= 5 \times 2 + 4 \times 1 = 14$$

**০২। $(x + 5)^2 = x^2 + bx + c$ সমীকরণে $b$ ও $c$ এর মান কত হলে সমীকরণটি অভেদ হবে? [৪৫তম বিসিএস]**
(ক) $3, 10$  (খ) $10, 15$  (গ) $15, 25$  (ঘ) $10, 25$

**সমাধান:**  
এখানে, $(x + 5)^2 = x^2 + bx + c$  
$\Rightarrow x^2 + 2 \cdot x \cdot 5 + (5)^2 = x^2 + bx + c$  
$\Rightarrow x^2 + 10x + 25 = x^2 + bx + c$  

সমীকরণের উভয়পক্ষে সহগ সমীকৃত করে পাই,  
$b = 10$ এবং $c = 25$

**উত্তর:** **(ঘ)**

**০৩। $p + q = 5$ এবং $p - q = 3$ হলে $p^2 + q^2$ এর মান কত? [৪৫তম বিসিএস]**

(ক) $8$  (খ) $17$  (গ) $19$  (ঘ) $34$

**সমাধান:**  
দেওয়া আছে, $p + q = 5$ ; $p - q = 3$  
$$\therefore p^2 + q^2 = \frac{1}{2} \{(p + q)^2 + (p - q)^2\}$$
$$= \frac{1}{2} \{(5)^2 + (3)^2\}$$
$$= \frac{1}{2} (25 + 9)$$
$$= \frac{1}{2} \times 34 = 17$$

**উত্তর:** **(খ)**

**০৪। $a + b = 7$ এবং $ab = 12$ হলে, $\frac{1}{a^2} + \frac{1}{b^2}$ এর মান কত? [৪১তম বিসিএস]**

(ক) $\frac{3}{25}$  
(খ) $\frac{25}{144}$  
(গ) $\frac{31}{144}$  
(ঘ) $\frac{11}{49}$

**সমাধান:**  
প্রদত্ত রাশি, $\frac{1}{a^2} + \frac{1}{b^2} = \frac{a^2 + b^2}{a^2 b^2}$  
$$= \frac{(a+b)^2 - 2ab}{(ab)^2}$$
$$= \frac{(7)^2 - 2 \times 12}{(12)^2}$$
$$= \frac{49 - 24}{144} = \frac{25}{144}$$

**উত্তর:** **(খ)**

**০৫। $x - y = 2$ এবং $xy = 24$ হলে, $x$ -এর ধনাত্মক মানটি- [৩৫তম বিসিএস]**
(ক) $3$  (খ) $4$  (গ) $5$  (ঘ) $6$

**সমাধান:**  
আমরা জানি,  
$(x + y)^2 = (x - y)^2 + 4xy$  
$= (2)^2 + 4 \cdot 24$  
$= 4 + 96$  
$= 100$  
$\therefore x + y = \pm 10$  

ধনাত্মক মান নিয়ে $x + y = 10 \dots\dots\dots (i)$  
$x - y = 2 \dots\dots\dots (ii)$  

এখন $(i) + (ii)$ করে পাই, $2x = 12 \therefore x = 6$

**উত্তর:** **(ঘ)**

**০৬। যদি $a + b = 2, ab = 1$ হয় তবে $a$ এবং $b$ এর মান যথাক্রমে- [৩১তম বিসিএস]**

(ক) $0, 2$  (খ) $1, 1$  (গ) $-1, 3$  (ঘ) $-3, -4$

**সমাধান:**  
$a + b = 2 \dots\dots\dots (i)$  
$\Rightarrow (a + b)^2 = (2)^2$ [উভয় পক্ষকে বর্গ করে]  
$\Rightarrow (a - b)^2 + 4ab = 4$ [সূত্র]  
$\Rightarrow (a - b)^2 + 4 \times 1 = 4$ [$\because ab = 1$]  
$\Rightarrow (a - b)^2 = 4 - 4$  
$\Rightarrow (a - b)^2 = 0$  
$\therefore a - b = 0 \dots\dots\dots (ii)$  

$(i) + (ii)$ করে পাই, $a + b + a - b = 2 + 0$  
$\Rightarrow 2a = 2 \therefore a = 1$  

এখন, $a$ এর মান $(i)$ নং সমীকরণে বসালে,  
$1 + b = 2 \Rightarrow b = 2 - 1 \therefore b = 1$

**উত্তর:** **(খ)**

**০৭। $a + b = 7$ এবং $a^2 + b^2 = 25$ হলে নিচের কোনটি $ab$ এর মান হবে? [৩০তম বিসিএস]**
(ক) $12$  (খ) $10$  (গ) $6$  (ঘ) কোনটিই নয়

**সমাধান:**  
দেওয়া আছে, $a^2 + b^2 = 25$  
$\Rightarrow (a + b)^2 - 2ab = 25$  
$\Rightarrow 7^2 - 2ab = 25$ [$\because a + b = 7$]  
$\Rightarrow 2ab = 24 \therefore ab = 12$

**উত্তর:** **(ক)**

**০৮। যদি $(x - y)^2 = 14$ এবং $xy = 2$ হয় তবে $x^2 + y^2 =$ কত? [২৭তম বিসিএস]**
(ক) $12$  (খ) $14$  (গ) $16$  (ঘ) $18$

**সমাধান:**  
$$x^2 + y^2 = (x - y)^2 + 2xy$$
$$= 14 + 2 \times 2 = 18$$

**উত্তর:** **(ঘ)**

**০৯। $x + y = 8, x - y = 6$ হলে, $x^2 + y^2$ এর মান- [২৬তম বিসিএস]**
(ক) $40$  (খ) $60$  (গ) $50$  (ঘ) $80$

**সমাধান:**  
$$x^2 + y^2 = \frac{1}{2} \{(x + y)^2 + (x - y)^2\}$$
$$= \frac{1}{2} \{(8^2 + 6^2)\}$$
$$= \frac{1}{2} \times 100 = 50$$

**উত্তর:** **(গ)**

**১০। $x + y = 6$ এবং $xy = 8$ হলে, $(x - y)^2$ -এর মান কত? [২৫তম বিসিএস]**
(ক) $4$  (খ) $6$  (গ) $8$  (ঘ) $12$

**সমাধান:**  
$$(x - y)^2 = (x + y)^2 - 4xy = 6^2 - 4 \times 8$$
$$= 36 - 32 = 4$$

**উত্তর:** **(ক)**

**১১। $x + y = 7$ এবং $xy = 10$ হলে, $(x - y)^2$-এর মান কত? [২৪তম বিসিএস]**
(ক) $3$  (খ) $6$  (গ) $9$  (ঘ) $12$

**সমাধান:**  
$$(x - y)^2 = (x + y)^2 - 4xy = 7^2 - 4 \times 10$$
$$= 49 - 40 = 9$$

**উত্তর:** **(গ)**

**১২। $x + y = 12$ এবং $x - y = 2$ হলে, $xy$-এর মান কত? [২২তম বিসিএস]**
(ক) $35$  (খ) $140$  (গ) $70$  (ঘ) $144$

**সমাধান:**  
আমরা জানি,  
$$xy = \frac{(x+y)^2 - (x-y)^2}{4} = \frac{12^2 - 2^2}{4}$$
$$= \frac{144 - 4}{4} = \frac{140}{4} = 35$$

**উত্তর:** **(ক)**

**১৩। $x^2 + y^2 = 8$ এবং $xy = 7$ হলে $(x + y)^2$ এর মান কত? [২০তম বিসিএস]**
(ক) $14$  (খ) $16$  (গ) $22$  (ঘ) $30$

**সমাধান:**  
$$(x + y)^2 = x^2 + 2xy + y^2 = x^2 + y^2 + 2xy$$
$$= 8 + 2 \times 7 \text{ [মান বসিয়ে]}$$
$$= 8 + 14 = 22$$

**উত্তর:** **(গ)**

**১৪। $\frac{1}{2} \{(a + b)^2 + (a - b)^2\} =$ কত? [১৪তম বিসিএস (শিক্ষা)]**
(ক) $a^2 + b^2$  (খ) $a^2 - b^2$  (গ) $\frac{(a+b)^2}{2} - \frac{(a-b)^2}{2}$  (ঘ) $(a + b)^2 + (a - b)^2$

**সমাধান:**  
$$\frac{1}{2} \{(a + b)^2 + (a - b)^2\}$$
$$= \frac{1}{2} (a^2 + 2ab + b^2 + a^2 - 2ab + b^2)$$
$$= \frac{1}{2} (2a^2 + 2b^2) = \frac{1}{2} \times 2 (a^2 + b^2) = a^2 + b^2$$

**উত্তর:** **(ক)**

**১৫। $a + b = 5$ এবং $a - b = 3$ হলে, $ab$ এর মান কত? [১০তম বিসিএস]**
(ক) $2$  (খ) $3$  (গ) $4$  (ঘ) $5$

**সমাধান:**  
আমরা জানি,  
$$ab = \left(\frac{a+b}{2}\right)^2 - \left(\frac{a-b}{2}\right)^2 = \left(\frac{5}{2}\right)^2 - \left(\frac{3}{2}\right)^2$$
$$= \frac{25}{4} - \frac{9}{4} = \frac{25 - 9}{4} = \frac{16}{4} = 4$$

**উত্তর:** **(গ)**


### **নমুনা প্রশ্ন ও সমাধান**
---
**০১। যদি $a = 17$ এবং $b = 11$ হয় তবে $a^2 - 2ab + b^2 = ?$**
(ক) $36$  (খ) $289$  (গ) $100$  (ঘ) $374$

**সমাধান:**  
প্রদত্ত রাশি, $a^2 - 2ab + b^2 = (a - b)^2$  
$= (17 - 11)^2 \text{ [মান বসিয়ে পাই]}$  
$= 6^2 = 36$

**উত্তর:** **(ক)**

**০২। $p^2 + q^2 = 10$ এবং $pq = 7$ হয় তবে $(p + q)^2$ এর মান কত?**
(ক) $14$  (খ) $24$  (গ) $17$  (ঘ) $4$

**সমাধান:**  
আমরা জানি, $(p + q)^2 = p^2 + 2pq + q^2$  
$= p^2 + q^2 + 2 \times pq$  
$= 10 + 2 \times 7 \text{ [মান বসিয়ে পাই]}$  
$= 10 + 14 = 24$

**উত্তর:** **(খ)**

**০৩। $a + b = 7$ এবং $ab = 15$ হলে $a^2 + b^2 + 3ab =$ কত?**
(ক) $29$  (খ) $64$  (গ) $69$  (ঘ) $34$

**সমাধান:**  
প্রদত্ত রাশি, $a^2 + b^2 + 3ab = a^2 + 2ab + b^2 + ab$  
$= (a + b)^2 + ab = (7)^2 + 15 \text{ [মান বসিয়ে পাই]}$  
$= 49 + 15 = 64$

**উত্তর:** **(খ)**

**০৪। যদি $(x + y)^2 = 30$ এবং $xy = 4$ হয় তবে $x^2 + y^2 =$ কত?**
(ক) $38$  (খ) $22$  (গ) $34$  (ঘ) $26$

**সমাধান:**  
প্রদত্ত রাশি, $(x + y)^2 = 30$  
$\Rightarrow x^2 + 2xy + y^2 = 30$  
$\Rightarrow x^2 + y^2 = 30 - 2xy$  
$\Rightarrow x^2 + y^2 = 30 - 2 \times 4 \text{ [মান বসিয়ে পাই]}$  
$\Rightarrow x^2 + y^2 = 22$

**উত্তর:** **(খ)**

**০৫। $a + b = 5$ এবং $a - b = 2$ হলে, $a^2 + b^2$ এর মান কত?**
(ক) $2$  (খ) $29$  (গ) $\frac{29}{2}$  (ঘ) $25$

**সমাধান:**  
আমরা জানি, $2(a^2 + b^2) = (a + b)^2 + (a - b)^2$  
$\Rightarrow 2(a^2 + b^2) = (5)^2 + (2)^2$  
$\Rightarrow 2(a^2 + b^2) = 29 \therefore a^2 + b^2 = \frac{29}{2}$

**উত্তর:** **(গ)**
