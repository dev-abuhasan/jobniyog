### **Type 01: বীজগাণিতিক রাশির সাধারণ সরলীকরণ**

<p align="left">
1.  \(a-[a-\{a-(a-\overline{a-1})\}]\) = ?[36 BCS]
</p>

```
= a-[a-{a-(a-a+1)}]
= a-[a-{a-1}]
= a-[a-a-1]
= a-1
```
2. a=1, b=-1, c=2, d=-2 then a-(-b)-(-c)-(-d) = ? [15 BCS]
```
= a+b+c+d
= 1+(-1)+2+(-2)
= 1-1+2-2
= 0
```

**প্রশ্ন:** $\frac{a^2 + b^2 - c^2 + 2ab}{a^2 - b^2 + c^2 + 2ac} =$ কত?

---

### **সমাধান:**

**ধাপ ১: পদগুলো সাজিয়ে বর্গের সূত্রে আনয়ন**

* **লব:** 
  $$a^2 + 2ab + b^2 - c^2 = (a + b)^2 - c^2$$

* **হর:** 
  $$a^2 + 2ac + c^2 - b^2 = (a + c)^2 - b^2$$

---

**ধাপ ২: $x^2 - y^2 = (x + y)(x - y)$ সূত্র প্রয়োগ**

$$\frac{(a + b)^2 - c^2}{(a + c)^2 - b^2}$$

$$= \frac{(a + b + c)(a + b - c)}{(a + c + b)(a + c - b)}$$

$$= \frac{(a + b + c)(a + b - c)}{(a + b + c)(a - b + c)}$$

---

**ধাপ ৩: লঘুকরণ (সাধারণ পদ $a + b + c$ কাটাকাটি)**

$$= \frac{a + b - c}{a - b + c}$$

---

**উত্তর:** **(খ)** $\frac{a + b - c}{a - b + c}$
