## **১০.১: উৎপাদকে বিশ্লেষণ**

### **মৌলিক ধারণাসমূহ:**
* **প্রতীক (Symbol):** যে সংখ্যা বা অক্ষর দ্বারা কোনো কিছুর পরিমাণ প্রকাশ করা হয় তাকে প্রতীক বলা হয়। বীজগণিতে দুই ধরনের প্রতীক রয়েছে:
  1. সংখ্যা প্রতীক: যেমন: $1, 2, 5$
  2. অক্ষর প্রতীক: যেমন: $x, y, z$
* **চলক (Variable):** যে কোনো ধরনের অজ্ঞাত রাশি বা অক্ষর প্রতীককে বীজগণিতীয় চলক বলা হয়।
  * চলকের মান পরিবর্তনশীল।
  * চলকের মান নির্দিষ্ট নয়।
  * কোনো রাশিতে একাধিক চলক থাকতে পারে।
* **পদ (Term):** বীজগণিতে পৃথক পৃথক কোনো সংখ্যা বা অক্ষর প্রতীককে পদ বলা হয়। যেমন: $1, 8, x, 3x^2, 7y$ ইত্যাদি।
* **রাশি (Expression):** প্রক্রিয়া চিহ্ন ও সংখ্যাসূচক প্রতীকের অর্থবোধক সংযোগ বা বিন্যাসকে বীজগণিতীয় রাশি বলা হয়। যেমন: $4x^3 + 6xy - 15xy^2, 3a - 5b, 2x + 4y - 5z$ ইত্যাদি।
  * পদ পৃথক হয় যোগ ও বিয়োগ চিহ্নের মাধ্যমে। যেমন: $3a - 2b$
  * একাধিক পদের গুণফল ও ভাগফলও তাই একটি পদ হিসেবে বিবেচিত হয়। যেমন: $3x \times \frac{x}{2}$
* **সহগ (Coefficient):** সহগ হলো কোনো বীজগণিতীয় রাশির উৎপাদক।
  * কোনো বর্ণ বা অক্ষর দিয়ে সহগ গঠিত হলে তাকে বর্ণমূলক সহগ (Literal Coefficient) বলে।
  * আবার, কেবল সংখ্যা দিয়ে সহগ গঠিত হলে তাকে সংখ্যামূলক সহগ (Numerical Coefficient) বলে।  
    > *উদাহরণ:* $3ax^2$ বীজগণিতীয় পদটিতে $3$ হলো $ax^2$ এর সংখ্যামূলক সহগ এবং $3a$ হলো $x^2$ এর সহগ। আবার $abx$ পদটিতে $ab$ হলো $x$ এর বর্ণমূলক সহগ।  
    > সহগ সাধারণত কোনো পদের বাঁ দিকে লেখা হয়, যদি কোনো পদে সহগের উল্লেখ না থাকে, তবে সহগ হিসেবে $1$ ধরতে হয়। যেমন: $x^2$ এর সহগ $1$।
* **উৎপাদক (Factor):** কোনো রাশি দুই বা ততধিক রাশির গুণফলের সমান হলে, শেষোক্ত রাশিগুলোর প্রত্যেকটিকে প্রথমোক্ত রাশির উৎপাদক বা গুণনীয়ক বলা হয়। কোনো বীজগণিতীয় রাশিকে প্রাপ্ত উৎপাদকগুলোর গুণফল আকারে প্রকাশ করাকে **উৎপাদকে বিশ্লেষণ** বলা হয়।

বীজগণিতীয় রাশিগুলো এক বা একাধিক পদবিশিষ্ট হতে পারে। নিম্নে ছকের মাধ্যমে বিষয়টি তুলে ধরা হলো:

| রাশি | উৎপাদকে বিশ্লেষিত রাশি |
| :--- | :--- |
| $x^2 - y^2$ | $(x + y)(x - y)$ |
| $x^3 - 1$ | $(x - 1)(x^2 + x + 1)$ |
| $x^3 - y^3$ | $(x - y)(x^2 + xy + y^2)$ |
| $x^2 + 5x + 6$ | $(x + 2)(x + 3)$ |

### **উৎপাদকে বিশ্লেষণের সাধারণ মাধ্যমসমূহ:**
1. সদৃশ পদ বা সংখ্যা 'Common' নেয়া।
2. সূত্র প্রয়োগ।
3. Middle term বা মধ্যরাশিকে বিশ্লেষণ করা।
4. ফাংশন এবং ভাগশেষ উপপাদ্যের প্রয়োগ।

## **Type 01: সূত্রাবলির ব্যবহার ও সাধারণ পদ 'Common' নিয়ে উৎপাদকে বিশ্লেষণ**

কোনো বহুপদী রাশির প্রতিটি পদে কোনো সাধারণ উৎপাদক থাকলে সেটিকে আগে উৎপাদক হিসেবে বের করে নিলে উৎপাদকে বিশ্লেষণ করা সহজ হয়। যেমন:
$$y^2 + xy + 3y = y(y + x + 3)$$
এখানে $y^2 + xy + 3y$ রাশির প্রতিটি পদে সাধারণ উৎপাদক $y$। অন্য উৎপাদক $(y + x + 3)$ একটি মৌলিক উৎপাদক। সুতরাং এটি একটি উৎপাদকে বিশ্লেষণ।

* **উদাহরণ:** $x^2 + 3y^3 - xy - 3xy^2$ কে উৎপাদকে বিশ্লেষণ করো।  
  **সমাধান:**  
  $$x^2 + 3y^3 - xy - 3xy^2 = x^2 - xy - 3xy^2 + 3y^3$$
  $$= x(x - y) - 3y^2(x - y) = (x - y)(x - 3y^2)$$

কিছু কিছু বহুপদী রাশি আছে, যে রাশিগুলোকে পূর্ণবর্গ আকারে প্রকাশ করা যায়। যেমন: $x^2 + 6xy + 9y^2$  
এটিকে আমরা লিখতে পারি, $x^2 + 2 \cdot x \cdot 3y + (3y)^2 = (x + 3y)^2$  
এই ধরনের রাশিকে একই রাশির গুণফল হিসেবে প্রকাশ করা যায়, অর্থাৎ $(x + 3y)^2 = (x + 3y)(x + 3y)$।

কোনো বহুপদী রাশিকে দুইটি রাশির বর্গের অন্তররূপে প্রকাশ করতে চাইলে আমরা নিচের সূত্র ব্যবহার করে তা করতে পারি:  
$$x^2 - y^2 = (x + y)(x - y)$$

* **উদাহরণ:** $x^2 + 4x + 1$ উৎপাদকে বিশ্লেষণ করো।  
  **সমাধান:**  
  $$x^2 + 4x + 1 = x^2 + 2 \cdot x \cdot 2 + 2^2 - 3 = (x + 2)^2 - (\sqrt{3})^2$$
  সূত্রানুযায়ী আমরা লিখতে পারি,
  $$x^2 + 4x + 1 = (x + 2 + \sqrt{3})(x + 2 - \sqrt{3})$$

অনেক সময় $ax^2 + bx + c \ [a \neq 0]$ আকারের বহুপদী রাশির মধ্যপদকে সুবিধাজনকভাবে বিভক্ত করা যায় না। তখন বিভিন্ন বুদ্ধি খাটিয়ে উৎপাদকে বিশ্লেষণ করতে হয়।

$$ax^2 + bx + c = a\left(x^2 + \frac{b}{a}x + \frac{c}{a}\right) = a\left\{x^2 + 2 \cdot x \cdot \frac{b}{2a} + \left(\frac{b}{2a}\right)^2 - \left(\frac{b}{2a}\right)^2 + \frac{c}{a}\right\}$$
$$= a\left\{\left(x + \frac{b}{2a}\right)^2 - \left(\frac{b^2 - 4ac}{4a^2}\right)\right\} = a\left\{\left(x + \frac{b}{2a}\right)^2 - \left(\frac{\sqrt{b^2 - 4ac}}{2a}\right)^2\right\}$$
$$= a\left(x + \frac{b}{2a} + \frac{\sqrt{b^2 - 4ac}}{2a}\right)\left(x + \frac{b}{2a} - \frac{\sqrt{b^2 - 4ac}}{2a}\right)$$
$$= a\left(x + \frac{b + \sqrt{b^2 - 4ac}}{2a}\right)\left(x + \frac{b - \sqrt{b^2 - 4ac}}{2a}\right)$$

এখানে দ্বিঘাত বহুপদী রাশিটি সরল বহুপদী রাশির মাধ্যমে উৎপাদকে বিশ্লেষণ করা হয়েছে। লক্ষ্য করো যে, $b^2 - 4ac$ এর মান ঋণাত্মক হলে, অর্থাৎ $b^2 - 4ac < 0$ হলে, দ্বিঘাত বহুপদী রাশিটি সরল বহুপদী রাশির মাধ্যমে উৎপাদকে বিশ্লেষণ করা যাবে না। এমতাবস্থায়, $ax^2 + bx + c, [a \neq 0]$ দ্বিঘাত রাশিটি একটি বাস্তব মৌলিক রাশি। অর্থাৎ $ax^2 + bx + c, [a \neq 0]$ রাশিকে বাস্তব মানের সাপেক্ষে আর উৎপাদকে বিশ্লেষণ করা যাবে না।

### **Type 01: বিগত BCS প্রিলি পরীক্ষার প্রশ্ন ও সমাধান**

**০১। $x^2 - y^2 + 2y - 1$ এর একটি উৎপাদক— [৩২তম ও ২৬তম বিসিএস]**  
(ক) $x + y + 1$  (খ) $x - y$  (গ) $x + y - 1$  (ঘ) $x - y - 1$  
* **সমাধান:**  
  $$x^2 - y^2 + 2y - 1 = x^2 - (y^2 - 2y + 1) = x^2 - (y - 1)^2$$
  $$= (x + y - 1)(x - y + 1)$$
  **উত্তর:** **(গ)**

**০২। $a^4 + 4$ এর উৎপাদক কি কি? [১২তম বিসিএস]**  
(ক) $(a^2 + 2a + 2)(a^2 - 2a - 2)$  
(খ) $(a^2 + 2a + 2)(a^2 - 2a + 2)$  
(গ) $(a^2 - 2a + 2)(a^2 + 2a - 2)$  
(ঘ) $(a^2 - 2a - 2)(a^2 - 2a + 2)$  
* **সমাধান:**  
  $$a^4 + 4 = \{(a^2)^2 + 2 \cdot a^2 \cdot 2 + 2^2\} - 2a^2 \cdot 2 = (a^2 + 2)^2 - (2a)^2$$
  $$= (a^2 + 2 + 2a)(a^2 + 2 - 2a) = (a^2 + 2a + 2)(a^2 - 2a + 2)$$
  **উত্তর:** **(খ)**

### **Type 01: নমুনা প্রশ্ন ও সমাধান**

**০১। $1 - a^2 + 2ab - b^2$ এর উৎপাদক কোনটি?**  
(ক) $(1 + a + b)(1 - a + b)$  
(খ) $(1 + a + b)(1 - a - b)$  
(গ) $(1 + a + b)(1 + a - b)$  
(ঘ) $(1 + a - b)(1 - a + b)$  
* **সমাধান:**  
  $$1 - a^2 + 2ab - b^2 = 1 - (a^2 - 2ab + b^2) = 1^2 - (a - b)^2$$
  $$= \{1 + (a - b)\}\{1 - (a - b)\} = (1 + a - b)(1 - a + b)$$
  **উত্তর:** **(ঘ)**

**০২। $ax^2 + (a^2 + 1)x + a$ এর উৎপাদক কোনটি?**  
(ক) $(x - a)(ax - 1)$  
(খ) $(x + a)(ax - 1)$  
(গ) $(x + a)(ax + 1)$  
(ঘ) কোনটিই নয়  
* **সমাধান:**  
  $$ax^2 + (a^2 + 1)x + a = ax^2 + a^2x + x + a = ax(x + a) + 1(x + a) = (x + a)(ax + 1)$$
  **উত্তর:** **(গ)**

**০৩। $a^2 + 6a + 8 - y^2 + 2y$ এর উৎপাদক কোনটি?**  
(ক) $a + y + 4$  
(খ) $(a + y + 2)(a - y + 4)$  
(গ) $a - y - 4$  
(ঘ) $(a + 3)(y + 1)(a + y)$  
* **সমাধান:**  
  $$a^2 + 6a + 8 - y^2 + 2y = a^2 + 6a + 8 - (y^2 - 2y \cdot 1 + 1^2) + 1$$
  $$= a^2 + 6a + 9 - (y - 1)^2 = a^2 + 2 \cdot a \cdot 3 + 3^2 - (y - 1)^2$$
  $$= (a + 3)^2 - (y - 1)^2 = (a + 3 + y - 1)(a + 3 - y + 1) = (a + y + 2)(a - y + 4)$$
  **উত্তর:** **(খ)**

**০৪। $4a^2 + \frac{1}{4a^2} - 2 + 4a - \frac{1}{a}$ এর উৎপাদক কোনটি?**  
(ক) $2a + \frac{1}{2a}$  
(খ) $\left(2a - \frac{1}{2a}\right)^2$  
(গ) $\left(2a - \frac{1}{2a}\right)\left(2a - \frac{1}{2a} + 2\right)$  
(ঘ) $\left(2a - \frac{1}{2a}\right)\left(2 - \frac{1}{2a} + 1\right)$  
* **সমাধান:**  
  $$4a^2 + \frac{1}{4a^2} - 2 + 4a - \frac{1}{a} = (2a)^2 - 2 \cdot 2a \cdot \frac{1}{2a} + \left(\frac{1}{2a}\right)^2 + 4a - \frac{1}{a}$$
  $$= \left(2a - \frac{1}{2a}\right)^2 + 2\left(2a - \frac{1}{2a}\right) = \left(2a - \frac{1}{2a}\right)\left(2a - \frac{1}{2a} + 2\right)$$
  **উত্তর:** **(গ)**

**০৫। $27x^4 + 8xy^3$ এর উৎপাদক বিশ্লেষণে নিম্নের কোন রাশিটি পাওয়া যায় না?**  
(ক) $x$  (খ) $3x$  (গ) $(3x + 2y)$  (ঘ) $(9x^2 - 6xy + 4y^2)$  
* **সমাধান:**  
  $$27x^4 + 8xy^3 = x(27x^3 + 8y^3) = x\{(3x)^3 + (2y)^3\}$$
  $$= x(3x + 2y)\{(3x)^2 - 3x \cdot 2y + (2y)^2\} = x(3x + 2y)(9x^2 - 6xy + 4y^2)$$
  **উত্তর:** **(খ)**

**০৬। $8x^3 + 36x^2y + 54xy^2 + 27y^3$ এর উৎপাদক কোনটি?**  
(ক) $(2x + 3y)(2x - 4y)$  (খ) $(2x + 12xy)$  (গ) $(2x + 3y)(2x + 3y)(2x + 3y)$  (ঘ) কোনোটিই নয়  
* **সমাধান:**  
  $$8x^3 + 36x^2y + 54xy^2 + 27y^3 = (2x)^3 + 3 \cdot (2x)^2 \cdot 3y + 3 \cdot 2x \cdot (3y)^2 + (3y)^3$$
  $$= (2x + 3y)^3 = (2x + 3y)(2x + 3y)(2x + 3y)$$
  **উত্তর:** **(গ)**

**০৭। $a^2 - c^2 + 2ab + b^2$ এর উৎপাদক কোনটি?**  
(ক) $(a + b + c)(a - b + c)$  (খ) $(a - b - c)(a - b + c)$  (গ) $(a - b - c)(a + b - c)$  (ঘ) $(a + b + c)(a + b - c)$  
* **সমাধান:**  
  $$a^2 - c^2 + 2ab + b^2 = a^2 + 2ab + b^2 - c^2 = (a + b)^2 - c^2 = (a + b + c)(a + b - c)$$
  **উত্তর:** **(ঘ)**

**০৮। $8a^3 + \frac{b^3}{27}$ এর উৎপাদক নয় কোনটি?**  
(ক) $6a + b$  (খ) $36a^2 - 6ab + b^2$  (গ) $6a - b$  (ঘ) কোনোটিই নয়  
* **সমাধান:**  
  $$8a^3 + \frac{b^3}{27} = (2a)^3 + \left(\frac{b}{3}\right)^3 = \left(2a + \frac{b}{3}\right)\left\{(2a)^2 - 2a \cdot \frac{b}{3} + \left(\frac{b}{3}\right)^2\right\}$$
  $$= \left(2a + \frac{b}{3}\right)\left(4a^2 - \frac{2ab}{3} + \frac{b^2}{9}\right) = \left(\frac{6a + b}{3}\right)\left(\frac{36a^2 - 6ab + b^2}{9}\right)$$
  $$= \frac{1}{27}(6a + b)(36a^2 - 6ab + b^2)$$
  **উত্তর:** **(গ)**

## **Type 02: Middle term/মধ্যপদ বিশ্লেষণ করে সমস্যার সমাধান নির্ণয়**

$x^2 + ax + b$ আকারের রাশির সহগ $a$ কে একটি নির্দিষ্ট পদ্ধতিতে বিভক্ত করে উৎপাদকে বিশ্লেষণ করা যায়। এক্ষেত্রে $a$ এর মানকে এমনভাবে দুইটি সংখ্যা $c$ এবং $d$ তে বিভক্ত করতে হয় যাদের যোগফল $a$ এর সমান এবং গুণফল $b$ এর সমান হয়। তখন নিচের সূত্র ব্যবহার করে আমরা উৎপাদকে বিশ্লেষণ করতে পারি।
$$x^2 + (c + d)x + cd = (x + c)(x + d)$$

রাশির আকার $ax^2 + bx + c$ হলে, $b$ এর মানকে এমনভাবে দুইটি সংখ্যা $d$ এবং $c$ তে বিভক্ত করতে হয় যাদের যোগফল $b$ এর সমান এবং গুণফল $ac$ এর সমান হয়। পরে সাধারণ উৎপাদক বের করার মাধ্যমে আমরা উৎপাদকে বিশ্লেষণ করতে পারি।

### **Type 02: বিগত BCS প্রিলি পরীক্ষার প্রশ্ন ও সমাধান**

**০১। $2x^2 + x - 15$-এর উৎপাদক কোনটি? [২৪তম বিসিএস]**  
(ক) $(x + 3)(2x - 5)$  (খ) $(x - 3)(2x - 5)$  (গ) $(x - 3)(2x + 5)$  (ঘ) $(x + 3)(2x + 5)$  
* **সমাধান:**  
  $$2x^2 + x - 15 = 2x^2 + 6x - 5x - 15 = 2x(x + 3) - 5(x + 3) = (x + 3)(2x - 5)$$
  **উত্তর:** **(ক)**

**০২। $2x^2 - x - 15$ এর উৎপাদক হবে— [১২তম বিসিএস]**  
(ক) $(x + 6)(x - 5)$  (খ) $(x - 5)(x - 6)$  (গ) $(x + 3)(2x - 5)$  (ঘ) $(2x + 5)(x - 3)$  
* **সমাধান:**  
  $$2x^2 - x - 15 = 2x^2 - 6x + 5x - 15 = 2x(x - 3) + 5(x - 3) = (2x + 5)(x - 3)$$
  **উত্তর:** **(ঘ)**

### **Type 02: নমুনা প্রশ্ন ও সমাধান**

**০১। $6p^2 - 7p - 5$ এর উৎপাদক বিশ্লেষণে নিম্নের কোন রাশিটি পাওয়া যায় না?**  
(ক) $1 + 2p$  (খ) $3p - 5$  (গ) $3p + 5$  (ঘ) কোনোটিই নয়  
* **সমাধান:**  
  $$6p^2 - 7p - 5 = 6p^2 + 3p - 10p - 5 = 3p(2p + 1) - 5(2p + 1)$$
  $$= (2p + 1)(3p - 5) = (1 + 2p)(3p - 5)$$
  **উত্তর:** **(গ)**

**০২। $2a^2 + 7ab - 15b^2$ এর উৎপাদক কোনটি?**  
(ক) $(a + 5b)(2a + 3b)$  (খ) $(a + 5b)(2a - 3b)$  (গ) $(a - 5b)(2a + 3b)$  (ঘ) কোনোটিই নয়  
* **সমাধান:**  
  $$2a^2 + 7ab - 15b^2 = 2a^2 + 10ab - 3ab - 15b^2 = 2a(a + 5b) - 3b(a + 5b) = (a + 5b)(2a - 3b)$$
  **উত্তর:** **(খ)**

**০৩। $x^2 - x - 20$ এর উৎপাদক কোনটি?**  
(ক) $(x - 5)(x - 4)$  (খ) $(x + 5)(x - 4)$  (গ) $(x - 5)(x + 4)$  (ঘ) $(x + 5)(x + 4)$  
* **সমাধান:**  
  $$x^2 - x - 20 = x^2 - 5x + 4x - 20 = x(x - 5) + 4(x - 5) = (x - 5)(x + 4)$$
  **উত্তর:** **(গ)**

**০৪। $10p^2 + 11pq - 6q^2$ এর উৎপাদক কোনটি?**  
(ক) $2p - 3q$  (খ) $5p + 2q$  (গ) $(2p + 3q)(5p - 2q)$  (ঘ) কোনোটিই নয়  
* **সমাধান:**  
  $$10p^2 + 11pq - 6q^2 = 10p^2 + 15pq - 4pq - 6q^2 = 5p(2p + 3q) - 2q(2p + 3q) = (2p + 3q)(5p - 2q)$$
  **উত্তর:** **(গ)**

**০৫। $x^2 - 37x - 650$ এর উৎপাদক কোনটি?**  
(ক) $(x - 50)(x + 13)$  (খ) $(x + 50)(x - 13)$  (গ) $(x - 50)(x - 13)$  (ঘ) $(x + 50)(x + 13)$  
* **সমাধান:**  
  $$x^2 - 37x - 650 = x^2 - 50x + 13x - 650 = x(x - 50) + 13(x - 50) = (x - 50)(x + 13)$$
  **উত্তর:** **(ক)**

## **Type 03: সাধারণ পদকে $x, p, q$ ইত্যাদি ধরে সমাধান নির্ণয়**

এ প্রকরণে কোনো বীজগণিতীয় রাশিতে বৃহদাকার পদকে চলক ($x, y, z, p, q......$ ইত্যাদি) ধরে তুলনামূলক ছোট রাশিতে পরিণত করা হয়। অতঃপর উৎপাদকে বিশ্লেষণ করা হয়।

### **Type 03: নমুনা প্রশ্ন ও সমাধান**

**০১। $x^2 + x - (a + 1)(a + 2)$ এর উৎপাদক নিম্নের কোনটি?**  
(ক) $(x - a - 3)(x + a + 2)$  
(খ) $(x - a - 2)$  
(গ) $(x - a - 1)(x + a + 2)$  
(ঘ) $(x + 1)(x + 2)$  
* **সমাধান:**  
  প্রদত্ত রাশি $= x^2 + x - (a + 1)(a + 2) = x^2 + x - (a + 1)(a + 1 + 1)$
  $$= x^2 + x - p(p + 1) \quad [\text{ধরি, } a + 1 = p]$$
  $$= x^2 + x - p^2 - p = x^2 - p^2 + x - p = (x + p)(x - p) + (x - p)$$
  $$= (x - p)(x + p + 1)$$
  এখন $p$ এর মান বসিয়ে পাই,
  $$= (x - a - 1)(x + a + 1 + 1) = (x - a - 1)(x + a + 2)$$
  **উত্তর:** **(গ)**

**০২। $(x^2 - x)^2 + 3(x^2 - x) - 40$ এর উৎপাদক কোনটি?**  
(ক) $(2x + 8)(x^2 - x - 5)$  
(খ) $(5x - 8)(5x - 5)$  
(গ) $(x^2 - x + 8)(x^2 - x - 5)$  
(ঘ) কোনটিই নয়  
* **সমাধান:**  
  ধরি, $x^2 - x = p$
  $$\therefore \text{প্রদত্ত রাশি} = p^2 + 3p - 40 = p^2 + 8p - 5p - 40 = p(p + 8) - 5(p + 8) = (p + 8)(p - 5)$$
  এখন $p$ এর মান বসিয়ে পাই,
  $$= (x^2 - x + 8)(x^2 - x - 5)$$
  **উত্তর:** **(গ)**

**০৩। $(x + 2)(x + 3)(x + 4)(x + 5) - 48$ এর উৎপাদক কোনটি?**  
(ক) $(x^2 + 7x + 18)(x^2 + 7x + 4)$  
(খ) $(x^2 - 7x + 18)(x^2 - 7x + 4)$  
(গ) $(x^2 - 7x - 18)(x^2 - 7x - 4)$  
(ঘ) $(x^2 + 7x + 18)(x^2 - 7x - 4)$  
* **সমাধান:**  
  $$\text{প্রদত্ত রাশি} = \{(x + 2)(x + 5)\}\{(x + 3)(x + 4)\} - 48$$
  $$= (x^2 + 2x + 5x + 10)(x^2 + 3x + 4x + 12) - 48 = (x^2 + 7x + 10)(x^2 + 7x + 12) - 48$$
  ধরি, $x^2 + 7x + 10 = a \implies x^2 + 7x + 12 = x^2 + 7x + 10 + 2 = a + 2$
  $$\therefore \text{প্রদত্ত রাশি} = a(a + 2) - 48 = a^2 + 2a - 48 = a^2 + 8a - 6a - 48$$
  $$= a(a + 8) - 6(a + 8) = (a + 8)(a - 6)$$
  এখন $a$ এর মান বসিয়ে পাই,
  $$= (x^2 + 7x + 10 + 8)(x^2 + 7x + 10 - 6) = (x^2 + 7x + 18)(x^2 + 7x + 4)$$
  **উত্তর:** **(ক)**

**০৪। $x^2 - x - (a + 1)(a + 2)$ এর উৎপাদক কোনটি?**  
(ক) $(2x + a - 1)(2x - a + 1)$  
(খ) $(x - a - 1)(x - 1)$  
(গ) $(x + a + 1)(x - a - 1)$  
(ঘ) $(x + a + 1)(x - a - 2)$  
* **সমাধান:**  
  $$\text{প্রদত্ত রাশি} = x^2 - x - (a + 1)(a + 1 + 1)$$
  $$= x^2 - x - m(m + 1) \quad [\text{ধরি, } a + 1 = m]$$
  $$= x^2 - x - m^2 - m = (x + m)(x - m) - (x + m) = (x + m)(x - m - 1)$$
  এখন $m$ এর মান বসিয়ে পাই,
  $$= (x + a + 1)(x - (a + 1) - 1) = (x + a + 1)(x - a - 1 - 1) = (x + a + 1)(x - a - 2)$$
  **উত্তর:** **(ঘ)**

**০৫। $(a - 1)x^2 + a^2xy + (a + 1)y^2$ এর উৎপাদক নিচের কোনটি?**  
(ক) $(x - ay + y)(ax - x + y)$  
(খ) $(x + ay + y)(ax - x + y)$  
(গ) $(x - ay - y)(ax - x + y)$  
(ঘ) $(x + ay + y)(ax + x - y)$  
* **সমাধান:**  
  $$\text{মনে করি, } a - 1 = p \quad \text{এবং} \quad a + 1 = q$$
  $$\text{গুণ করে, } a^2 - 1 = pq \implies a^2 = pq + 1$$
  $$\therefore \text{প্রদত্ত রাশি} = px^2 + (pq + 1)xy + qy^2 = px^2 + pqxy + xy + qy^2$$
  $$= px(x + qy) + y(x + qy) = (x + qy)(px + y)$$
  এখন $p$ ও $q$ এর মান বসিয়ে পাই,
  $$= \{x + (a + 1)y\}\{(a - 1)x + y\} = (x + ay + y)(ax - x + y)$$
  **উত্তর:** **(খ)**

## **Type 04: ভাগশেষ উপপাদ্য**

### **ভাগশেষ উপপাদ্য:**
উৎপাদকে বিশ্লেষণের ক্ষেত্রে এমন কিছু রাশি রয়েছে যাদেরকে অন্যান্য নিয়ম যেমন 'Common' বা 'Middle term' পদ্ধতিতে সূত্রের আকারে প্রকাশ করা যায় না। এক্ষেত্রে 'ভাগশেষ উপপাদ্য' নামক বিশেষ পদ্ধতির সাহায্য নিতে হবে। ভাগশেষ উপপাদ্যের সাহায্যে যে-কোনো বহুপদীর উৎপাদকে বিশ্লেষণ করা যায়।

ধরি, $f(x)$ একটি বহুপদী। এটিকে $x - a$ আকারের বহুপদী দ্বারা ভাগ করলে ভাগশেষ কত হবে তা ভাগ না করে বের করার পদ্ধতিকে বলা হয় ভাগশেষ উপপাদ্য। এ পদ্ধতির সাহায্যে উৎপাদক নির্ণয়ের পদ্ধতিকে শূন্যায়ন পদ্ধতি 'Vanishing Method'-ও বলা হয়।

ধরি, $f(x) = x^4 - 4x + 3$  
এখানে, $x$ এর মান $1$ হলে, $f(1) = (1)^4 - 4 \cdot 1 + 3 = 1 - 4 + 3 = 0$  
সুতরাং $(x - 1)$, $f(x)$ এর একটি উৎপাদক।

অন্যভাবে বলা যায়, $f(x) = x^4 - 4x + 3$ এর একটি উৎপাদক $(x - 1)$ হলে $f(1) = 0$ হবে।

* **উৎপাদক উপপাদ্য:** যদি $p(x)$ ধনাত্মক মাত্রার বহুপদী হয় এবং $p(a) = 0$ হয় তবে $p(x)$ এর একটি উৎপাদক হবে $x - a$।
* **উৎপাদক উপপাদ্যের বিপরীত উপপাদ্য:** $x - a$ যদি $p(x)$ বহুপদীর একটি উৎপাদক হয় তবে $p(a) = 0$ হবে।

### **Type 04: বিগত BCS প্রিলি পরীক্ষার প্রশ্ন ও সমাধান**

**০১। যদি $5x^3 - 2x^2 + x + k = 0$ এর একটি উৎপাদক $(x - 3)$ হয়, তাহলে $k$ এর মান কত? [৪৭তম বিসিএস]**  
(ক) $50$  (খ) $60$  (গ) $-120$  (ঘ) $-60$  
* **সমাধান:**  
  এখানে, বহুপদীটির একটি উৎপাদক $(x - 3)$। অর্থাৎ বহুপদীটি $x = 3$ এর জন্য সিদ্ধ হবে।  
  তাহলে, বহুপদী সমীকরণে $x = 3$ বসিয়ে পাই,
  $$5x^3 - 2x^2 + x + k = 0$$
  $$\Rightarrow 5 \times (3)^3 - 2 \times (3)^2 + 3 + k = 0$$
  $$\Rightarrow 5 \times 27 - 2 \times 9 + 3 + k = 0$$
  $$\Rightarrow 135 - 18 + 3 + k = 0$$
  $$\Rightarrow 120 + k = 0 \implies k = -120$$
  **উত্তর:** **(গ)**

**০২। $x^3 - x^2$ কে $x - 2$ দ্বারা ভাগ করলে অবশেষ থাকবে— [৩১তম বিসিএস]**  
(ক) $2$  (খ) $4$  (গ) $-6$  (ঘ) $-8$  
* **সমাধান:**  
  ধরি, $f(x) = x^3 - x^2$  
  $f(x)$ কে $(x - 2)$ দ্বারা ভাগ করলে ভাগশেষ হবে $f(2)$।
  $$\therefore f(2) = 2^3 - 2^2 = 8 - 4 = 4$$
  **উত্তর:** **(খ)**

**০৩। $3x^3 + 2x^2 - 21x - 20$ রাশিটির একটি উৎপাদক হচ্ছে— [৩০তম বিসিএস]**  
(ক) $x + 2$  (খ) $x - 2$  (গ) $x + 1$  (ঘ) $x - 1$  
* **সমাধান:**  
  ধরি, $f(x) = 3x^3 + 2x^2 - 21x - 20$
  $$\therefore f(-1) = 3(-1)^3 + 2(-1)^2 - 21(-1) - 20 = -3 + 2 + 21 - 20 = 0$$
  যেহেতু $x$ এর পরিবর্তে $-1$ বসালে প্রদত্ত রাশিটির মান শূন্য ($0$) হয়।  
  অতএব, $\{x - (-1)\} = (x + 1)$ প্রদত্ত রাশিটির একটি উৎপাদক।  
  **উত্তর:** **(গ)**

**০৪। যদি $x^3 + hx + 10 = 0$ এর একটি সমাধান $2$ হয়, তবে $h$ এর মান কত? [১৩তম বিসিএস]**  
(ক) $10$  (খ) $9$  (গ) $-9$  (ঘ) $2$  
* **সমাধান:**  
  প্রদত্ত সমীকরণের একটি সমাধান $2$ হলে, $x = 2$ এর জন্য সমীকরণটি সিদ্ধ হবে—  
  অর্থাৎ $2^3 + h \times 2 + 10 = 0$
  $$\Rightarrow 8 + 2h + 10 = 0 \implies 2h + 18 = 0 \implies h = -9$$
  **উত্তর:** **(গ)**

**০৫। $(x + 3)(x - 3)$ কে $x^2 - 6$ দিয়ে ভাগ করলে ভাগশেষ কত হবে? [১১তম বিসিএস]**  
(ক) $-6$  (খ) $3$  (গ) $6$  (ঘ) $-3$  
* **সমাধান:**  
  ধরি, $f(x) = (x + 3)(x - 3) = x^2 - 9$  
  $f(x)$ কে $x^2 - 6$ দ্বারা ভাগ করলে ভাগশেষ হবে $f(\sqrt{6})$।
  $$\therefore f(\sqrt{6}) = (\sqrt{6})^2 - 9 = 6 - 9 = -3$$
  অতএব, ভাগশেষ $= -3$  
  **উত্তর:** **(ঘ)**

### **Type 04: নমুনা প্রশ্ন ও সমাধান**

**০১। $ax^3 + bx^2 + cx + d$ এর একটি উৎপাদক $(x - 1)$ হলে, $a + b + c + d$ এর মান কত?**  
(ক) $0$  (খ) $-1$  (গ) $1$  (ঘ) কোনোটিই নয়  
* **সমাধান:**  
  ধরি, $P(x) = ax^3 + bx^2 + cx + d$
  $$\therefore P(1) = a(1)^3 + b(1)^2 + c(1) + d = a + b + c + d$$
  উৎপাদক উপপাদ্যের বিপরীত উপপাদ্যের সাহায্যে পাই, $P(1) = 0 \implies a + b + c + d = 0$  
  **উত্তর:** **(ক)**

**০২। নিচের কোনটি $P(x) = x^3 - 6x^2 + 11x - 6$ এর উৎপাদক নয়?**  
(ক) $x - 1$  (খ) $x + 2$  (গ) $x - 2$  (ঘ) কোনোটিই নয়  
* **সমাধান:**  
  ধরি, $P(x) = x^3 - 6x^2 + 11x - 6$
  $$\therefore P(1) = 1 - 6 + 11 - 6 = 0$$
  আবার, $P(2) = 2^3 - 6 \cdot 2^2 + 11 \cdot 2 - 6 = 8 - 24 + 22 - 6 = 0$  
  এবং $P(-2) = (-2)^3 - 6(-2)^2 + 11(-2) - 6 = -8 - 24 - 22 - 6 = -60$  
  যেহেতু $P(-2) \neq 0$,  
  $\therefore (x + 2)$, $P(x)$ এর উৎপাদক হতে পারে না।  
  **উত্তর:** **(খ)**

**০৩। $f(x) = 2x^3 - 5x^2 + 7x - 8$ কে $(x - 2)$ দ্বারা ভাগ করলে ভাগশেষ কত হবে?**  
(ক) $16$  (খ) $30$  (গ) $2$  (ঘ) কোনোটিই নয়  
* **সমাধান:**  
  এখানে, $f(x) = 2x^3 - 5x^2 + 7x - 8$  
  ভাগশেষ উপপাদ্য অনুযায়ী, $f(x)$ কে $(x - 2)$ দ্বারা ভাগ করলে ভাগশেষ হবে:
  $$f(2) = 2(2)^3 - 5(2)^2 + 7 \times 2 - 8 = 2 \times 8 - 20 + 14 - 8 = 30 - 28 = 2$$
  **উত্তর:** **(গ)**

**০৪। $x^3 - 3x^2 + 4x - 4$ রাশিটির উৎপাদক হচ্ছে—**  
(ক) $(x + 2)(x^2 - x + 2)$  
(খ) $(x - 2)(x^2 - x + 2)$  
(গ) $(x - 2)(x^2 + x + 2)$  
(ঘ) $(x - 2)(x^2 - x - 2)$  
* **সমাধান:**  
  ধরি, $f(x) = x^3 - 3x^2 + 4x - 4$
  $$\therefore f(2) = 2^3 - 3 \cdot 2^2 + 4 \cdot 2 - 4 = 8 - 12 + 8 - 4 = 16 - 16 = 0$$
  $\therefore (x - 2)$, $f(x)$ এর একটি উৎপাদক।  
  এখন, $x^3 - 3x^2 + 4x - 4 = x^3 - 2x^2 - x^2 + 2x + 2x - 4$
  $$= x^2(x - 2) - x(x - 2) + 2(x - 2) = (x - 2)(x^2 - x + 2)$$
  **উত্তর:** **(খ)**

**০৫। $(x + 5)(x - 9) - 15$ এর উৎপাদক কোনটি?**  
(ক) $x + 10$  (খ) $x - 10$  (গ) $x - 8$  (ঘ) $x - 6$  
* **সমাধান:**  
  ধরি, $f(x) = (x + 5)(x - 9) - 15$  
  এখন অপশন টেস্ট করে $f(x) = 0$ হলে সেই অপশনই নির্ণেয় উৎপাদক হবে।
  $$\therefore f(-10) = (-10 + 5)(-10 - 9) - 15 = (-5)(-19) - 15 = 95 - 15 = 80$$
  $$\therefore f(10) = (10 + 5)(10 - 9) - 15 = 15 \times 1 - 15 = 15 - 15 = 0$$
  $\therefore (x + 5)(x - 9) - 15$ এর একটি উৎপাদক হলো $x - 10$  
  **উত্তর:** **(খ)**

**০৬। $2x^4 - 3x^3 - 3x - 2$ এর নিচের কোন উৎপাদকটি সংশ্লিষ্ট নহে?**  
(ক) $x - 2$  (খ) $2x + 1$  (গ) $x^2 - 1$  (ঘ) $x^2 + 1$  
* **সমাধান:**  
  ধরি, $f(x) = 2x^4 - 3x^3 - 3x - 2$
  $$\therefore f(2) = 2 \times 2^4 - 3 \times 2^3 - 3 \times 2 - 2 = 32 - 24 - 6 - 2 = 32 - 32 = 0$$
  $\therefore (x - 2)$ প্রদত্ত ফাংশনের একটি উৎপাদক।  
  এখন, $2x^4 - 3x^3 - 3x - 2 = 2x^4 - 4x^3 + x^3 - 2x^2 + 2x^2 - 4x + x - 2$
  $$= 2x^3(x - 2) + x^2(x - 2) + 2x(x - 2) + 1(x - 2) = (x - 2)(2x^3 + x^2 + 2x + 1)$$
  $$= (x - 2)\{x^2(2x + 1) + 1(2x + 1)\} = (x - 2)(2x + 1)(x^2 + 1)$$
  [এই ৩টিই উৎপাদক]  
  সুতরাং, রাশিটির উৎপাদক নয়, অপশন (গ) $x^2 - 1$  
  **উত্তর:** **(গ)**

### **বিগত BCS প্রিলি পরীক্ষার প্রশ্ন ও সমাধান**

**০১। দুইটি সংখ্যার ল.সা.গু. $4x^2 + 12x^2 - 16x - 48$ গ.সা.গু. $2x + 4$। একটি সংখ্যা $4x^2 + 20x + 24$ হলে অপরটি— [৪৯তম বিসিএস (শিক্ষা)]**  
(ক) $x^2 - 4$  (খ) $2(x^2 - 4)$  (গ) $4(x^2 - 4)$  (ঘ) $x + 2$  
* **সমাধান:**  
  আমরা জানি, দুটি সংখ্যার গুণফল $= \text{ল.সা.গু.} \times \text{গ.সা.গু.}$  
  তাহলে, $(4x^2 + 20x + 24) \times \text{অপর সংখ্যা} = (4x^3 + 12x^2 - 16x - 48) \times (2x + 4)$
  $$\therefore \text{অপর সংখ্যা} = \frac{(16x^2 - 16x - 48) \times (2x + 4)}{4(x^2 + 5x + 6)} = \frac{16(x^2 - x - 3) \times 2(x + 2)}{4(x^2 + 5x + 6)}$$
  $$= \frac{8(x^2 - x - 3) \times (x + 2)}{(x + 3)(x + 2)} = \frac{8\times(x^2 - x - 3)}{x + 3}$$
  **উত্তর:** **Blank** *(প্রশ্নে টাইপিং ভুলের কারণে অপশনে সঠিক মান নেই)*

**০২। $x^2y + xy^2$ এবং $x^2 + xy$ রাশিদ্বয়ের ল.সা.গু. এবং গ.সা.গু. এর গুণফল কত? [৪৫তম বিসিএস]**  
(ক) $x^2y^2(x + y)$  (খ) $xy(x^2 + y^2)$  (গ) $x^2y(x + y)^2$  (ঘ) $xy^2(x^2 + y)$  
* **সমাধান:**  
  প্রথম রাশি $= x^2y + xy^2 = xy(x + y)$  
  দ্বিতীয় রাশি $= x^2 + xy = x(x + y)$  
  $\therefore \text{রাশিদ্বয়ের ল.সা.গু.} = xy(x + y)$  
  এবং $\text{গ.সা.গু.} = x(x + y)$  
  সুতরাং, $\text{ল.সা.গু. ও গ.সা.গু. এর গুণফল} = x(x + y) \times xy(x + y) = x^2y(x + y)^2$  
  **উত্তর:** **(গ)**

**০৩। $6a^2bc$ এবং $4a^3b^2c^2$ এর সংখ্যা সহগের গ.সা.গু. নিচের কোনটি? [৪৪তম বিসিএস]**  
(ক) $a^2bc$  (খ) $2a^2bc$  (গ) $2a^2b^2c^2$  (ঘ) কোনোটিই নয়  
* **সমাধান:**  
  এখানে, প্রদত্ত রাশির সংখ্যা সহগ $6$ ও $4$  
  এবং $6$ ও $4$ এর গ.সা.গু. $= 2$  
  কিন্তু অপশনে সঠিক উত্তরটি নাই।  
  সুতরাং, উত্তর হবে কোনোটিই নয়।  
  **উত্তর:** **(ঘ)**

**০৪। $x^3 + x^2y, x^2y + xy^2$ এর ল.সা.গু. কোনটি? [৩২তম বিসিএস]**  
(ক) $xy$  (খ) $x + y$  (গ) $xy(x + y)$  (ঘ) $x^2y(x + y)$  
* **সমাধান:**  
  ১ম রাশি, $x^3 + x^2y = x^2(x + y)$  
  এবং ২য় রাশি, $x^2y + xy^2 = xy(x + y)$  
  $\therefore \text{নির্ণেয় ল.সা.গু.} = x^2y(x + y)$  
  **উত্তর:** **(ঘ)**

**০৫। $(4x^2 - 16)$ এবং $6x^2 + 24x + 24$ এর গ.সা.গু. — [৩১তম বিসিএস]**  
(ক) $x + 2$  (খ) $x + 4$  (গ) $x + 2$  (ঘ) $2(x + 2)$  
* **সমাধান:**  
  ১ম রাশি, $4x^2 - 16 = 4(x^2 - 4) = 4(x^2 - 2^2) = 2 \cdot 2(x + 2)(x - 2)$  
  এবং ২য় রাশি, $6x^2 + 24x + 24 = 6(x^2 + 4x + 4) = 6(x^2 + 2 \cdot x \cdot 2 + 2^2) = 2 \cdot 3(x + 2)^2$  
  $\therefore \text{নির্ণেয় গ.সা.গু.} = 2(x + 2)$  
  **উত্তর:** **(ঘ)**

**০৬। $x^2 - 11x + 30$ এবং $x^3 - 4x^2 - 2x - 15$ এর গ.সা.গু. কত? [২৫তম বিসিএস]**  
(ক) $x - 5$  (খ) $x - 6$  (গ) $x^2 + x + 3$  (ঘ) $x^2 - x + 3$  
* **সমাধান:**  
  ১ম রাশি, $x^2 - 11x + 30 = x^2 - 6x - 5x + 30 = x(x - 6) - 5(x - 6) = (x - 6)(x - 5)$  
  আবার, ২য় রাশি, $x^3 - 4x^2 - 2x - 15$  
  $x = 5$ হলে, $5^3 - 4 \cdot 5^2 - 2 \cdot 5 - 15 = 0$  
  $x = 5$ বসালে রাশিটির মান শূন্য হয়।  
  $\therefore (x - 5)$ ২য় রাশিটির একটি উৎপাদক।  
  $x^3 - 4x^2 - 2x - 15 = x^3 - 5x^2 + x^2 - 5x + 3x - 15$
  $$= x^2(x - 5) + x(x - 5) + 3(x - 5) = (x - 5)(x^2 + x + 3)$$
  $\therefore \text{নির্ণেয় গ.সা.গু.} = (x - 5)$  
  **উত্তর:** **(ক)**

### **বীজগণিতীয় ল.সা.গু. ও গ.সা.গু.: নমুনা প্রশ্ন ও সমাধান**

**০১। $x^3 - 1, x^3 + 1, x^4 + x^2 + 1$ এর ল.সা.গু. কত?**  
(ক) $x^6 + 1$  (খ) $x^3 - 1$  (গ) $x^6 - 1$  (ঘ) $x^3 + 1$  
* **সমাধান:**  
  ১ম রাশি, $x^3 - 1 = (x - 1)(x^2 + x + 1)$  
  ২য় রাশি, $x^3 + 1 = (x + 1)(x^2 - x + 1)$  
  ৩য় রাশি, $x^4 + x^2 + 1 = (x^2)^2 + 2 \cdot x^2 \cdot 1 + 1^2 - x^2 = (x^2 + 1)^2 - (x)^2 = (x^2 + x + 1)(x^2 - x + 1)$  
  $\therefore \text{নির্ণেয় ল.সা.গু.} = (x - 1)(x^2 + x + 1)(x + 1)(x^2 - x + 1)$
  $$= (x^3 - 1)(x^3 + 1) = (x^3)^2 - (1)^2 = x^6 - 1$$
  **উত্তর:** **(গ)**

**০২। $x^2 + 5x, x^2 - 25$ এবং $x^2 + 7x + 10$ এর গ.সা.গু. কত?**  
(ক) $x - 5$  (খ) $x + 5$  (গ) $x(x + 5)$  (ঘ) $x(x + 5)(x - 5)(x + 2)$  
* **সমাধান:**  
  ১ম রাশি, $x^2 + 5x = x(x + 5)$  
  ২য় রাশি, $x^2 - 25 = x^2 - 5^2 = (x + 5)(x - 5)$  
  এবং ৩য় রাশি, $x^2 + 7x + 10 = x^2 + 5x + 2x + 10 = x(x + 5) + 2(x + 5) = (x + 5)(x + 2)$  
  $\therefore \text{নির্ণেয় গ.সা.গু.} = (x + 5)$  
  **উত্তর:** **(খ)**

**০৩। $x^2 - y^2, (x + y)^2, x^3 + y^3$ এর গ.সা.গু. কত?**  
(ক) $x - y$  (খ) $x + y$  (গ) $(x^2 - y^2)(x^3 + y^3)$  (ঘ) $(x - y)(x + y)^2(x^2 - xy + y^2)$  
* **সমাধান:**  
  ১ম রাশি, $x^2 - y^2 = (x + y)(x - y)$  
  ২য় রাশি, $(x + y)^2 = (x + y)(x + y)$  
  এবং ৩য় রাশি, $x^3 + y^3 = (x + y)(x^2 - xy + y^2)$  
  সুতরাং $\text{গ.সা.গু.} = (x + y)$  
  **উত্তর:** **(খ)**
