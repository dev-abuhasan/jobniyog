# BCS Math — Learn Shortcuts

## 1. Pythagoras Theorem (পিথাগোরাসের উপপাদ্য)

সমকোণী ত্রিভুজে:

**A² = B² + C²**

- A = অতিভুজ (Hypotenuse), সবচেয়ে বড় বাহু
- B, C = বাকি দুই বাহু

### Case 1: অতিভুজ বের করতে হবে

যখন বাকি দুই বাহু দেওয়া থাকবে।

**Formula:** `A = √(B² + C²)`

Example: বাহু ৩ ও ৪

- A = √(3² + 4²)
- A = √(9 + 16)
- A = √25
- **A = 5**

### Case 2: ছোট বাহু বের করতে হবে

যখন অতিভুজ ও অন্য একটি বাহু দেওয়া থাকবে।

**Formula:** `B = √(A² - C²)`

Example: অতিভুজ ১৩, অন্য বাহু ৫

- B = √(13² - 5²)
- B = √(169 - 25)
- B = √144
- **B = 12**

### Case 3: অন্য ছোট বাহু বের করতে হবে

**Formula:** `C = √(A² - B²)`

Example: অতিভুজ ১০, অন্য বাহু ৬

- C = √(10² - 6²)
- C = √(100 - 36)
- C = √64
- **C = 8**

### Shortcut

- অতিভুজ বের করতে → বর্গ করে যোগ, তারপর বর্গমূল।
- ছোট বাহু বের করতে → অতিভুজের বর্গ থেকে অন্য বাহুর বর্গ বিয়োগ, তারপর বর্গমূল।
- এই সূত্র শুধু সমকোণী ত্রিভুজে প্রযোজ্য।

### Distance and Direction

বিভিন্ন দিকে চলার পর সরাসরি দূরত্ব বের করতে:

**Distance = √[(East − West)² + (North − South)²]**

একই দিকে দূরত্ব যোগ করো, বিপরীত দিকে দূরত্ব বিয়োগ করো।

Example 1: ৩ কিমি উত্তর, ৪ কিমি পূর্বে গেলে:

- Distance = √(3² + 4²)
- Distance = √25
- **Distance = 5 km**

Example 2: ৮ মিটার পূর্বে, ১৫ মিটার উত্তরে, ৮ মিটার পশ্চিমে গেলে:

- পূর্ব-পশ্চিমের অবশিষ্ট = ৮ − ৮ = ০
- উত্তর-দক্ষিণের অবশিষ্ট = ১৫ মিটার
- **সরাসরি দূরত্ব = ১৫ মিটার**

## 2. Successive Percentage Change (শতকরা পরিবর্তন)

### মূল সূত্র

**Net Change (%) = a + b + (a × b)/100**

- বৃদ্ধি হলে → Positive (+)
- হ্রাস হলে → Negative (−)
- উত্তর Positive হলে → মোট বৃদ্ধি
- উত্তর Negative হলে → মোট হ্রাস

### Case 1: দুটি বৃদ্ধি

Example: দাম ২০% বাড়ল, এরপর ১০% বাড়ল।

- a = +20, b = +10
- = 20 + 10 + (20 × 10)/100
- = 30 + 2
- **মোট বৃদ্ধি = 32%**

### Case 2: দুটি হ্রাস

Example: দাম ২০% কমল, এরপর ১০% কমল।

- a = −20, b = −10
- = −20 − 10 + (−20 × −10)/100
- = −30 + 2
- **মোট হ্রাস = 28%**

### Case 3: হ্রাসের পর বৃদ্ধি

Example: দাম ২৫% কমল, এরপর ২০% বাড়ল।

- a = −25, b = +20
- = −25 + 20 + (−25 × 20)/100
- = −5 − 5
- **মোট হ্রাস = 10%**

### Case 4: একই হারে হ্রাস ও বৃদ্ধি

Example: দাম ২০% কমল, এরপর ২০% বাড়ল।

- a = −20, b = +20
- = −20 + 20 + (−20 × 20)/100
- = 0 − 4
- **মোট হ্রাস = 4%**

### Case 5: হ্রাসের পর আগের অবস্থায় ফিরতে কত বৃদ্ধি দরকার?

**Required Increase (%) = [x / (100 − x)] × 100**

Example: দাম ২০% কমেছে।

- = [20 / (100 − 20)] × 100
- = (20 / 80) × 100
- **প্রয়োজনীয় বৃদ্ধি = 25%**

### Circle Area and Radius (বৃত্তের ক্ষেত্রফল)

বৃত্তের ক্ষেত্রফল ব্যাসার্ধের বর্গের সমানুপাতিক।

**Area ∝ r²**

তাই ব্যাসার্ধের শতকরা পরিবর্তন x হলে, ক্ষেত্রফলের পরিবর্তন:

**Net Change (%) = 2x + x²/100**

এখানে x ধনাত্মক হলে ব্যাসার্ধ বাড়ে এবং ঋণাত্মক হলে কমে।

Example 1: ব্যাসার্ধ ২০% কমলে:

- x = −20
- = 2(−20) + (−20)²/100
- = −40 + 4
- **ক্ষেত্রফল 36% কমবে।**

Example 2: ব্যাসার্ধ ১০% বাড়লে:

- x = +10
- = 2(10) + 10²/100
- = 20 + 1
- **ক্ষেত্রফল 21% বাড়বে।**

Shortcut: ক্ষেত্রফল \(r²\)-এর সমানুপাতিক, তাই ব্যাসার্ধের পরিবর্তনকে দুবার প্রয়োগ করে হিসাব করা যায়।

## 3. Set (সেট)

ধরি:

- P = {2, 3, 5, 7, 9}
- Q = {1, 3, 5, 6, 8}
- U = {1, 2, 3, 4, 5, 6, 7, 8, 9}

### Union (∪) — সব উপাদান

দুটি সেটের সব উপাদান নাও। একই উপাদান একবার লিখবে।

**P ∪ Q = {1, 2, 3, 5, 6, 7, 8, 9}**

### Intersection (∩) — সাধারণ উপাদান

দুটি সেটেই আছে, এমন উপাদান নাও।

**P ∩ Q = {3, 5}**

### Difference (−) — পার্থক্য

P-তে আছে, কিন্তু Q-তে নেই:

**P − Q = {2, 7, 9}**

Q-তে আছে, কিন্তু P-তে নেই:

**Q − P = {1, 6, 8}**

মনে রাখবে: P − Q ≠ Q − P

### Complement (′) — পরিপূরক সেট

Universal set U-তে আছে, কিন্তু P-তে নেই:

**P′ = U − P = {1, 4, 6, 8}**

### Element (∈) — উপাদান হিসেবে আছে

**3 ∈ P** → ৩, P সেটে আছে।

### Not Element (∉) — উপাদান হিসেবে নেই

**4 ∉ P** → ৪, P সেটে নেই।

### Subset (⊆) — উপসেট

A-এর সব উপাদান B-তে থাকলে, A হলো B-এর উপসেট।

Example:

- A = {2, 3}
- B = {2, 3, 5}
- **A ⊆ B**

### Empty Set (∅) — ফাঁকা সেট

যে সেটে কোনো উপাদান নেই।

Example:

- A = {1, 2}
- B = {3, 4}
- **A ∩ B = ∅**

### Number of Elements

n(P) দিয়ে P সেটে মোট উপাদানের সংখ্যা বোঝায়।

P = {2, 3, 5, 7, 9}

**n(P) = 5**

### BCS Shortcut

- ∪ = সব উপাদান, পুনরাবৃত্তি বাদ
- ∩ = সাধারণ উপাদান
- P − Q = P থেকে Q-এর উপাদান বাদ
- P′ = U থেকে P-এর উপাদান বাদ
- ∈ = আছে
- ∉ = নেই
- ⊆ = উপসেট
- ∅ = ফাঁকা সেট
- n(P) = উপাদানের সংখ্যা

## 4. Trigonometry (ত্রিকোণমিতি)

### সমকোণী ত্রিভুজের তিনটি বাহু

- **অতিভুজ (Hypotenuse):** সমকোণের বিপরীত বাহু; সবচেয়ে বড় বাহু।
- **লম্ব (Opposite):** নির্দিষ্ট কোণের বিপরীত বাহু।
- **ভূমি (Adjacent):** নির্দিষ্ট কোণের পাশে থাকা বাহু, অতিভুজ বাদে।

### sin, cos, tan, cot-এর সূত্র

ধরি, নির্দিষ্ট কোণ = θ

| অনুপাত | সূত্র |
|---|---|
| sin θ | লম্ব / অতিভুজ |
| cos θ | ভূমি / অতিভুজ |
| tan θ | লম্ব / ভূমি |
| cot θ | ভূমি / লম্ব |

মনে রাখার ট্রিক: **SOH–CAH–TOA**

- SOH → Sin = Opposite / Hypotenuse
- CAH → Cos = Adjacent / Hypotenuse
- TOA → Tan = Opposite / Adjacent
- cot θ = 1 / tan θ

কোন সূত্র নেবে, তা নির্ভর করবে প্রশ্নে দেওয়া কোণের সাপেক্ষে কোন দুটি বাহুর সম্পর্ক প্রয়োজন তার ওপর।

### গুরুত্বপূর্ণ কোণের মান

| কোণ θ | sin θ | cos θ | tan θ |
|---|---|---|---|
| 0° | 0 | 1 | 0 |
| 30° | 1/2 | √3/2 | 1/√3 |
| 45° | 1/√2 | 1/√2 | 1 |
| 60° | √3/2 | 1/2 | √3 |
| 90° | 1 | 0 | সংজ্ঞায়িত নয় |

### sin 45° = 1/√2 কীভাবে হয়?

একটি সমদ্বিবাহু সমকোণী ত্রিভুজের দুটি লম্ব বাহু ১ ও ১ ধরি।

পিথাগোরাস সূত্র অনুযায়ী:

- অতিভুজ² = 1² + 1²
- অতিভুজ² = 2
- অতিভুজ = √2

এখন,

- sin 45° = লম্ব / অতিভুজ
- sin 45° = 1 / √2

অতএব:

**sin 45° = 1/√2 = √2/2**

কারণ 1/√2-কে হর থেকে মূল সরাতে √2/√2 দিয়ে গুণ করলে √2/2 হয়।

### মই ও দেয়ালের অঙ্ক

প্রশ্ন: ১৬ মিটার লম্বা একটি মই ভূমির সঙ্গে ৪৫° কোণ করে দেয়ালে ঠেস দিয়ে রাখা আছে। দেয়ালে মইটি কত উচ্চতায় পৌঁছেছে?

ধরি, দেয়ালের উচ্চতা = x মিটার।

- মই = ১৬ মিটার → অতিভুজ
- দেয়ালের উচ্চতা = x → ৪৫° কোণের বিপরীত বাহু

তাই sin ব্যবহার করব:

- sin 45° = লম্ব / অতিভুজ
- 1/√2 = x/16
- x = 16/√2
- x = 8√2 মিটার
- x ≈ 11.31 মিটার

**উত্তর: 8√2 মিটার বা প্রায় ১১.৩১ মিটার।**

### কখন কোন অনুপাত নেবে?

- উচ্চতা (লম্ব) ও মই (অতিভুজ) → sin
- ভূমির দূরত্ব ও মই (অতিভুজ) → cos
- উচ্চতা (লম্ব) ও ভূমির দূরত্ব → tan

### ২৩° বা ২৫°-এর মতো কোণ হলে

সূত্র একই থাকবে। যেমন, ১৬ মিটার মই ভূমির সঙ্গে ২৫° কোণ করলে:

- sin 25° = x/16
- x = 16 × sin 25°
- sin 25° ≈ 0.4226
- x ≈ 6.76 মিটার

৩০°, ৪৫°, ৬০°-এর মতো পরিচিত কোণের মান মুখস্থ রাখা উপকারী। অন্য কোণের ক্ষেত্রে ক্যালকুলেটর, প্রশ্নে দেওয়া মান বা অপশন কাজে লাগতে পারে।

### দ্রুত মনে রাখার নিয়ম

- sin = লম্ব / অতিভুজ
- cos = ভূমি / অতিভুজ
- tan = লম্ব / ভূমি
- cot = ভূমি / লম্ব
- অতিভুজ বের করতে → √(লম্ব² + ভূমি²)
- ছোট বাহু বের করতে → √(অতিভুজ² − অন্য বাহু²)

**সতর্কতা:** লম্ব ও ভূমি নির্ভর করে কোন কোণকে ধরে হিসাব করছ তার ওপর। কিন্তু অতিভুজ সবসময় সমকোণের বিপরীত বাহু।
