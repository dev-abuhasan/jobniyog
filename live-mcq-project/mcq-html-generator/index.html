Payload extraction notes

  • No MCQ limit. Every question in every subject array under data.question is included unless you set “Max MCQs”.
  • Primary strategy: read the hex size from xx:T<hex>, and slice exactly N characters after the comma.
  • If “Subject key in payload” is blank, all arrays are merged. Otherwise only that key is used.
  • Each question keeps its source subject array name in meta.sourceSubject and as a tag.

Expected output fields

idtopicIdcontentoptionsexplanationtagsmeta

ID format matches sync-nav.js: abufc_<base36-timestamp>_<12-hex-random> for both question and option IDs.
